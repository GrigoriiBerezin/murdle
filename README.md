# Birthday Murdle — Case 0810

Персональная дедуктивная игра для дня рождения Анны.

## Локальный запуск

Открой `index.html` в браузере.

## GitLab Pages

1. Создай новый GitLab repository.
2. Загрузи `index.html`, `style.css`, `game.js` и `.gitlab-ci.yml`.
3. После запуска pipeline открой **Deploy > Pages**.
4. Ссылка на опубликованный сайт появится там.

Игра не использует backend. Прогресс матрицы и факт раскрытия дела сохраняются в localStorage браузера.
